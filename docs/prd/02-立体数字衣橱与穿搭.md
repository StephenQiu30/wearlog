# 立体数字衣橱与穿搭产品规格 (PRD - Woo 1:1 复刻版)

## 1. 摘要与核心 SLA 指标

本规格确立“Woo 1:1 复刻立体数字衣橱与 3D 画报走秀台”在纯 API 架构下的产品功能验收标准，依据 [REQ-02](../requirement/02-立体数字衣橱与穿搭.md) 与 [DES-02](../design/02-立体数字衣橱与穿搭.md)。

### 核心 SLA 与成本控制卡点
1. **端侧瞬时视差**：利用 `onnxruntime-web` 在用户端本地计算，**≤ 300ms (P95)** 内激活 2.5D 深度微动，**服务器算力成本 $0.00**；
2. **多模态打标与调色盘**：Gemini 2.0 Flash 提取风格标题/季节温标 + 5 色调色盘在 **≤ 1.5s (P95)** 内返回；
3. **单品解构与透明抠图**：Fal.ai BiRefNet/SAM 2 并发拆解多件单品透明底图在 **≤ 2.0s (P95)** 内就绪，整齐呈现于右栏；
4. **2D 原生试穿时效**：FASHN.ai / Fal.ai VTON 换装在 **≤ 2.5s (P95)** 内出图，原姿态与五官面部保持率 100%；
5. **360° 环绕生成时效**：16 关键帧与 WebP Sprite Sheet 生成在 **≤ 6.0s (P95)** 内就绪，超时熔断线 **25s**；
6. **单次体验总成本**：单用户完整体验（分析+5色盘+单品拆解+试穿+360°）云端综合成本严格控制在 **≤ 0.60 元人民币**。

1. **左栏（穿搭时光轴）**：默认 256px，可折叠；卡片包含缩略图、时令徽章（`☀️ SUMMER`）、日期（`JUL 18`）与风格标题；选中项左侧带指示圆点高亮；
2. **中栏（3D 画报走秀台）**：固定 `aspect-[3/4]` 比例，上部是大字号时尚标题与时令徽章；展台中央有人像与鼠标横向拖动微动效；左右翻页切换 Look，右边缘带下一套 Look 边缘微露；
3. **右栏（色彩与单品拆解）**：
   - `COLOR PALETTE`：5 个独立 Hex 纯净色块卡片，悬停显示代码；
   - `ITEMS IN THIS LOOK`：每个单品展示透明底 PNG、大写英文分类名、详细设计/面料文字、主色标签、以及一键收藏书签按钮（`🔖`）；
   - 底部操作栏：分享（Share）、海报导出（Download）、更多（...）。

## 3. 验收条件 (Acceptance Criteria)

| :--- | :--- | :--- | :--- | :--- |
| **AC-01** | FR-01、NFR-03 | 用户上传单张正向全身照 | 提交图片进行质检 | 正确识别单人与头脚完整度；自动归一化基线与居中留白；人像脚底严格对齐 88% 接地参考基线，**CLS = 0** |
| **AC-02** | FR-02、NFR-04 | 全身照加载进入浏览器 | 前端初始化 onnxruntime-web | **300ms 内**在客户端本地输出深度图，晃动手机/移动指针产生生动 2.5D 微动，云端算力消耗为 0 |
| **AC-03** | FR-03、FR-04 | 后端接收到全身照 URL | 调用 Gemini 2.0 Flash 与色彩聚类 | 1.5s 内返回季节、温标、时尚标题与 5 色调色盘；右栏准确渲染 5 个独立 Hex 纯净色块 |
| **AC-04** | FR-05、FR-06 | 视觉感知完成，获取单品边界 | 后端调用 Fal.ai BiRefNet/SAM 2 | 2.0s 内完成外套、上装、下装、鞋包并发抠图，生成透明底 PNG，并由 Gemini 填充专业版型/面料描述 |
| **AC-05** | FR-07 | 右栏展示拆解单品列表 | 用户点击某件单品卡片上的 `🔖` 按钮 | 单品入库当前用户的数字衣橱，书签图标即刻填充变亮，弹出 Toast 提示“已收藏进衣橱” |
| **AC-06** | FR-08、NFR-01 | 选定衣橱中某件单品，展台展示人物 | 点击“试穿” | 后端调用 VTON API，**2.5s 内**生成保持原图姿势、面部发型与未换衣物的新 Look，服帖自然无穿模 |
| **AC-07** | FR-09、NFR-02 | 用户对当前 2D 试穿效果满意 | 点击“生成 360° 环绕” | 后端生成 16 正交视角并合成 4×4 WebP Sprite Sheet；**0° 视角强绑定原图**，旋转闭环无跳帧 |
| **AC-08** | FR-10、NFR-03 | 360° 精灵图加载完成 | 鼠标横向拖拽或手指轻扫展台 | Canvas 2D 维持稳定 **60fps**；指针停即画面停；显存常驻 ≤ 15MB，无内存泄漏与丢帧 |
| **AC-09** | FR-11 | 用户点击左栏历史卡片或中栏 `<` `>` | 切换浏览不同穿搭 | 中栏与右栏平滑过渡，主立绘、调色板与拆解单品同步更新，无闪烁布局偏移 |
| **AC-10** | FR-11 | 用户点击右栏底部的“下载”图标 | 触发画报导出 | 前端 Canvas 导出 300DPI 个人时尚画报海报（含主图立绘、5 色调色板、单品白底图与面料说明） |

| **AC-12** | NFR-06 | 切换不同用户登录 | 访问历史 Look 与衣橱单品 | 严格执行租户/用户隔离，私有 URL 签名合法，日志中无 API Key 泄露 |

## 4. AI 管道工程配置清单

| 管道环节 | 模型/服务选型 | 关键参数与 Prompt 配置 | 关键环境变量 |
| :--- | :--- | :--- | :--- |
| **时尚感知与解构** | Gemini 2.0 Flash | Temperature: `0.2`, TopP: `0.8`, Schema: 严格 JSON（含 title, season, min_temp, max_temp, style_tags, items[category, name, detailed_desc, material, box_2d]） | `GEMINI_API_KEY` |
| **高精度透明抠图** | Fal.ai BiRefNet / SAM 2 | 并发处理各目标 `box_2d`，输出 32 位 RGBA WebP/PNG，去除背景杂质 | `FAL_KEY` |
| **5 色调色盘提取** | CIELAB K-Means 聚类 | k=5，过滤透明像素与人体肤色遮罩，按面积与纯度排序输出 5 个 Hex | 无外部依赖 (Go 本地算法) |
| **2D 原生姿态试穿** | Fashn.ai API v1 / CatVTON | `category`: tops/bottoms/one-pieces, `nsfw_filter`: true, `restore_background`: true, `adjust_hands`: true | `FASHN_API_KEY` |
| **360° 新视角合成** | Fal.ai SV3D / Era3D | 16 方位角（步长 22.5°），仰角 0°，4×4 拼接为 2048×2732 WebP Sprite Sheet，Quality 85 | `FAL_KEY` |
| **端侧即时立体视差** | onnxruntime-web + MiDaS | WebAssembly/WebGL 本地执行，量化模型 12MB，≤ 300ms 纯端侧零算力成本 | 前端静态打包 |

## 5. 发布准入与工程规范审查

1. **后端 Google Go 规范审查通过**：
   - `internal/application/orbit/` 无包级全局可变状态，Context 作为第一参数显式传递并带超时保护；
   - 错误使用 `%w` 包裹且保持小写无标点；面向接口消费并以构造函数装配；
   - `cmd/server/main.go` 与 `cmd/openapi/main.go` 保持薄入口，`architecture_test.go` 守护通过。
2. **前端 Vercel 规范审查通过**：
   - 遵循 Geist 视觉体系，固定 `aspect-[3/4]` 容器保证 **CLS = 0**；
   - 保持 Server-First，`"use client"` 仅下沉至 Canvas 拖动器与 Dock 叶子组件；`onnxruntime-web` 实现动态懒加载。
3. **真实单套衣物闭环**：在一套基准人像、三套衣物上跑通“上传 $\rightarrow$ 拆解 $\rightarrow$ 5色提取 $\rightarrow$ 收藏衣橱 $\rightarrow$ 换装 $\rightarrow$ 360° 拖拽”全流程。
