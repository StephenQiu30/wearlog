# 预置虚拟模特与试穿人像产品规格 (PRD - Woo 1:1 复刻版)

## 1. 摘要与核心 SLA 指标

本规格确立“Woo / Wearlog 预置虚拟模特、开箱即用 3D 走秀体验与试穿人像载体”的产品功能验收标准，依据 [REQ-04](../requirement/04-预置虚拟模特与试穿人像.md) 与 [DES-04](../design/04-预置虚拟模特与试穿人像.md)。

### 核心 SLA 与体验指标
1. **预设模特首屏展现**：预制模特正面立绘与 16 帧 Sprite Sheet 加载耗时 **P95 ≤ 800ms**；
2. **冷启动即刻可用**：用户进入展台后在 **0 秒** 内即可无缝拖拽 3D 走秀台，无需等待上传或推理；
3. **2D 原生换装时效**：基于当前选定模特调用试穿快道出图时效 **P95 ≤ 2.5s**，五官与原生姿态 100% 保持；
4. **Canvas 2D 拖拽帧率**：拖拽旋转锁死稳定 **60fps**，显存常驻 **≤ 15MB**。

## 3. 验收条件 (Acceptance Criteria)

| 编号 | 对应需求 | Given 前置条件 | When 触发操作 | Then 预期结果 (客观可验证) |
| :--- | :--- | :--- | :--- | :--- |
| **AC-01** | MOD-FR-01、MOD-NFR-01 | 用户访问 `/orbit` 走秀台 | 页面加载完成 | 默认选中第一款预设模特（Maya），展台立即渲染 3D 立绘，800ms 内加载完精灵图 |
| **AC-02** | MOD-FR-01、MOD-NFR-02 | 预制模特加载在展台中 | 鼠标或手指在展台水平拖动 | Canvas 2D 稳定维持 60fps 帧率旋转，指针停即画面停，显存占用 ≤ 15MB |
| **AC-03** | MOD-FR-02 | 用户查看模特切换器 | 点击 `Leo (男模)` 胶囊 | 展台人像以 ≤ 200ms 的平滑过渡切换为男模 Leo，360° 拖拽切片与脚底软阴影即刻对齐 |
| **AC-04** | MOD-FR-03 | 当前展台为预置模特 Chloe | 在数字衣橱中点击一件新上装试穿 | 后端调用换装快道，2.5s 内返回新立绘，严格保持 Chloe 的发型、五官、站姿与未被换掉的裤子鞋履 |
| **AC-05** | MOD-FR-04 | 用户点击 `+ 上传本人照片` | 选取本地一张全身穿搭照上传 | 系统校验头顶留白与脚底位置，通过后作为自定义模特插入切换器列表，并自动选中展示 |
| **AC-06** | MOD-FR-04 | 用户上传了一张半身照或严重遮挡照 | 提交质检 | 明确拦截并友好提示“未能识别完整全身姿态，请上传包含头部和脚底的清晰穿搭照” |
| **AC-07** | MOD-FR-05 | 切换器展示多款模特 | 用户点击“设为默认试穿人像” | 状态持久化至本地或账户设置，下次打开走秀台自动恢复该模特 |
