# 人物环绕与立体数字衣橱产品规格 (PRD - 纯 API 架构版)

## 1. 摘要与核心 SLA 指标

本规格确立“Woo 1:1 复刻立体数字衣橱”在纯 API 架构下的产品功能验收标准，采用 [REQ-01](../requirement/01-人物环绕.md) revision 3、[DES-01](../design/01-人物环绕.md) revision 3、[RES-01](../research/01-人物环绕.md) revision 3。

### 核心 SLA 与成本控制卡点
1. **端侧瞬时视差**：利用 `onnxruntime-web` 在用户端本地计算，**≤ 300ms (P95)** 内激活 2.5D 深度微动，**服务器算力成本 $0.00**；
2. **多模态分析与单品解构**：Gemini 2.0 Flash 打标 + Fal.ai 单品抠图在 **≤ 1.5s (P95)** 内返回，单品整齐排列于底部 Dock；
3. **2D 原生试穿时效**：FASHN.ai / Fal.ai VTON 换装在 **≤ 2.5s (P95)** 内出图，原姿态与五官面部保持率 100%；
4. **360° 环绕生成时效**：16 关键帧与 WebP Sprite Sheet 生成在 **≤ 6.0s (P95)** 内就绪，超时熔断线 **25s**；
5. **单次体验总成本**：单用户完整体验（分析+拆解+试穿+360°）云端综合成本严格控制在 **≤ 0.60 元人民币**。

## 2. 验收条件 (Acceptance Criteria)

| 编号 | 对应需求 | Given 前置条件 | When 触发操作 | Then 预期结果 (客观可验证) |
| --- | --- | --- | --- | --- |
| **AC-01** | FR-01、NFR-01 | 用户上传单张正向全身照 | 提交图片进行质检 | 正确识别单人与头脚完整度；自动归一化基线与居中留白；人像脚底对齐 88% 接地参考基线 |
| **AC-02** | FR-02、NFR-04 | 全身照加载进入浏览器 | 前端初始化 onnxruntime-web | **300ms 内**在客户端本地输出深度图，晃动手机产生生动 2.5D 微动，云端算力消耗为 0 |
| **AC-03** | FR-03、FR-04 | 后端接收到全身照 URL | 异步调用 Gemini 与 Fal.ai | 1.5s 内返回季节、温标及风格标签，底部 Dock 弹出外套、上衣、裤子白底单品卡片 |
| **AC-04** | FR-05、NFR-01 | 底部 Dock 显示单品，展台展示人物 | 选中一件新单品点击试穿 | 后端调用 VTON API，**2.5s 内**生成保持原图姿势、面部发型与未换衣物的新 Look |
| **AC-05** | FR-06、NFR-02 | 用户对当前 2D 试穿 Look 满意 | 点击“生成 360° 环绕” | 后端生成 16 正交视角并合成 WebP Sprite Sheet；**0° 视角强绑定原图**，旋转闭环无跳帧 |
| **AC-06** | FR-07、NFR-03 | Sprite Sheet 资源就绪 | 手指在展台水平来回拖拽 | Canvas 2D 维持稳定 **60fps**；指针停即画面停；显存常驻 ≤ 15MB，无内存泄漏 |
| **AC-07** | NFR-05 | 后端完成 Huma 接口修改 | 前端运行 `npm run openapi` | 自动从 `/openapi.json` 生成强类型 Axios 客户端，TypeScript 编译通过，无手写类型冲突 |
| **AC-08** | NFR-04 | 遭遇外部 API 超时或队列阻塞超过 25s | 等待 360° 关键帧生成 | 触发熔断保护，状态标为 `failed_fallback`；弹窗提示并维持 2.5D 深度视差微动，不卡死 |
| **AC-09** | NFR-06 | 切换不同用户登录 | 访问历史 Look 与衣橱单品 | 严格执行租户/用户隔离，私有 URL 签名合法，日志中无 API Key 泄露 |

## 3. 发布准入与准出条件

1. **零 GPU 依赖验证**：服务端无需启动任何 Python 进程或挂载显卡驱动，仅凭 Go 二进制即可完整跑通全链路；
2. **前后端接口打通**：通过 `npm run openapi` 自动生成的 SDK 完成端到端调用；
3. **真实单套衣物闭环**：在一套基准人像、三套衣物上跑通“上传 $\rightarrow$ 拆解 $\rightarrow$ 换装 $\rightarrow$ 360° 拖拽”全流程。
