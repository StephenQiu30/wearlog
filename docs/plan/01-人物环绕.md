# 人物环绕

## 1. 规格与执行边界

采用 [REQ-01](../requirement/01-人物环绕.md)、[DES-01](../design/01-人物环绕.md)、[PRD-01](../prd/01-人物环绕.md)、[RES-01](../research/01-人物环绕.md)，均为 revision 1。

已授权范围是整理调研与当前 docs、确立照片质感和拖动效果优先、不参考当前代码。以下是后续验证与开发顺序，不是已经获准执行的收费生成、采购、部署或代码修改。当前没有产品实现任务就绪，也不以历史实现推断可复用模块。

每个实现任务进入 ready 前，必须补齐真实路径、测试输入、版本、依赖与验证方法；本计划不会为了形式完整虚构当前代码位置。FR/NFR 对应验收见 PRD 表，不能跳过视觉门槛直接进入代码任务。

## 3. 停止条件、回退与协作

静态图不满意则不创建环绕；环绕没有完成一圈或衣物变化明显则保留静态图并拒绝环绕。达到预先确定的费用/尝试上限即停止，不自动切供应商扩大支出。播放器失败回到素材和解码策略比较，不擅自切换低质量三维资产。

本主题文档与共享入口由本聊天主 agent 串行整合。当前不分派实现任务，不并行写共享文件；实际认领与状态只放在根 BACKLOG，验证摘要与接手位置放 HANDOVER。未来编码前，目标平台的旧说明若与照片帧方向冲突，应以本次用户确认优先并更新相应文档。

下一步从 T-01 收敛实验条件。读取顺序为研究 → 需求 → 设计 → PRD → 本计划；本增量不恢复已清理的历史文档或实验代码。
