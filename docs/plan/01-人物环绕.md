# 人物环绕与立体数字衣橱实施计划 (Vercel & Google Go 双规范版)

## 1. 规格与执行边界

采用 [REQ-01](../requirement/01-人物环绕.md) revision 3、[DES-01](../design/01-人物环绕.md) revision 4、[PRD-01](../prd/01-人物环绕.md) revision 4、[RES-01](../research/01-人物环绕.md) revision 3。

本计划落实**“零自建算力、纯 API 组装、Google Go 规范与 Vercel 规范落地”**的实施步骤，代码落点严格限定在 `wearlog-server/backend` 与 `wearlog-server/frontend`。

## 3. 验收与回退红线

1. 服务端遵循 Google Go 规范，禁止引入任何本地 Python 推理服务、GPU 容器依赖或包级全局可变状态；
2. 前端遵循 Vercel 规范，禁止在首屏 bundle 中同步打包 `onnxruntime-web`，展台容器必须固定比例防止布局抖动；
3. 任何外部第三方 API 响应超过 25s 必须自动触发熔断，降级保留静态 2.5D 深度视差；
4. 前后端交互必须严格通过 `openapi2ts` 自动生成的 SDK，禁止手写重复接口请求函数。
