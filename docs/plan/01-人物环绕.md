# 人物环绕与立体数字衣橱实施计划

## 1. 规格与执行边界

采用 [REQ-01](../requirement/01-人物环绕.md) revision 2、[DES-01](../design/01-人物环绕.md) revision 2、[PRD-01](../prd/01-人物环绕.md) revision 2、[RES-01](../research/01-人物环绕.md) revision 2。

本计划聚焦去除过度设计后的**务实落地实施**：先验证关键交互与轻量生成原型，杜绝向未经实测的 3D 引擎或 MP4 seek 分散工程精力。

## 2. 实施任务与里程碑分解

| 任务编号 | 任务名称与目标 | 对应 AC / 规格 | 核心产出与交付物 | 依赖项与通过标准 |
| --- | --- | --- | --- | --- |
| **T-01** | 实验基准样本与协议确定 | AC-01、AC-10 前提 | 确定 1 套基准全身人物图与 3 件代表性衣物（针织衫/衬衫/风衣）；固化 16 关键帧与 Sprite Sheet 规范 | 输入素材完备，消除模糊未知项 |
| **T-02** | 2.5D 深度微动与 Canvas 拖动原型 | AC-02、AC-06 | 验证 `Depth-Anything-V2` 灰度生成与前端视差微动着色器；验证 WebP Sprite Sheet Canvas 拖拽帧率 | P95 感知延迟 ≤ 300ms，拖动维持稳定 60fps，停止即停帧 |
| **T-03** | 单品解构与清洗打标管线 | AC-03、AC-07 | 搭建 `SAM 2` 自动切片 + LaMa 遮挡补全 + `Gemini 2.0 Flash` 季节/风格结构化 JSON 输出 | 准确识别品类，单品白底图边缘规整，打标耗时 ≤ 2s |
| **T-04** | 2D 原生姿态换装引擎接入 (快道) | AC-04 | 接入 `CatVTON / IDM-VTON`，基于原图骨架执行局部替换，输出保持面部/体态一致的新 Look | 换装耗时 P95 ≤ 2.5s，人脸与未替换部位零漂移 |
| **T-05** | 16 视角环绕生成与闭环消缝 (慢道) | AC-05、AC-08 | 接入 `Era3D / SV3D-Light`，固定 16 正交角度，0° 强绑定原图；打包输出 WebP Sprite Sheet | 单次生成 ≤ 8s，0° 接缝无感知跳动，25s 熔断兜底有效 |
| **T-06** | 端到端全链路串联与三套衣物回归 | AC-01～AC-10 | 上传全身照 $\rightarrow$ 2.5D 即刻反馈 $\rightarrow$ 拆解入库 $\rightarrow$ 换装 $\rightarrow$ 360° 拖拽查看 | 3 套衣物全部通过人工视觉评审，单套换装与环绕综合成本符合预算 |

## 3. 容灾与回退规则

1. 若 16 关键帧生成在极端情况下耗时超过 25s，系统自动熔断，不重试扣费，保持 2.5D 高清静态立体图；
2. 试穿结果若出现人脸漂移，自动拦截并回退至原 Look，提示用户微调单品；
3. 播放器严格锁定为 Canvas 2D + WebP Sprite Sheet，禁止回退到手势 Seek MP4 路线。
