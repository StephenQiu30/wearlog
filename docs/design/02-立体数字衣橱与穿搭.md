# 立体数字衣橱与穿搭系统设计 (Vercel & Google Go 双规范落地版)

## 1. 依据与核心设计决定

采用 [REQ-02](../requirement/02-立体数字衣橱与穿搭.md) 与 [RES-01](../research/01-人物环绕.md)。
本设计旨在 1:1 复刻 Woo 立体数字衣橱与 3D 画报走秀台，并严格贯彻两项工业级工程标准：
* **前端工程**：严格遵循 **Vercel 设计规范与 Next.js App Router 最佳实践**（Geist 视觉体系、三栏画报响应式流、Server-First 架构、零累积布局偏移 CLS=0、非阻塞水合）；
* **后端工程**：严格遵循 **Google Go Style Guide（Google Go 设计规范）**（接口隔离、Context 显式传播、显式错误包裹、无包级可变状态、并发生命周期控制）。

### 核心架构原则（避免过度设计）
1. **纯 API 编排，零 GPU 运维负担**：
   后端不自建任何 PyTorch/显卡进程，所有视觉与模型推理通过商业/Serverless API（Gemini 2.0 Flash、Fal.ai / FASHN.ai、Fal.ai SV3D）完成，空闲成本为 0；
2. **前后端全类型契约自动同步**：
   后端通过 Huma 导出标准 `/openapi.json`，前端通过 `npm run openapi`（`@umijs/openapi`）自动生成强类型 Axios 客户端，100% 编译期类型安全；
3. **分级体验与端侧零成本计算**：
   - 2.5D 深度视差由前端 `onnxruntime-web` 在用户浏览器本地运行，服务器算力成本为 0，300ms 内消除等待感；
   - 360° 交互由 **Canvas 2D + 16 关键帧 WebP Sprite Sheet** 实现，常驻显存仅约 12MB，真机稳定 60fps；
4. **全套穿搭解构与数字衣橱闭环**：
   - 自动生成 5 色 Hex 主色调色板（Color Palette）；
   - 并发输出透明底 PNG 单品与自然语言时尚面料描述；
   - 支持一键 Bookmark 收藏进数字衣橱，并由 2D 原生换装快道提供无缝试穿。

## 3. 模块职责与代码落点

| 职责模块 | 代码落点 | 技术实现与规范要求 |
| :--- | :--- | :--- |
| **三栏画报主界面** | `frontend/src/app/(site)/orbit/page.tsx` | Next.js Server Component 骨架，三栏响应式流布局，固定 3:4 比例 |
| **左栏时光轴卡片** | `frontend/src/components/orbit/look-sidebar.tsx` | 可折叠侧边栏，穿搭历史卡片列表，季节与日期徽章 |
| **中栏 3D 画报展台** | `frontend/src/components/orbit/runway-stage.tsx` | 居中立绘、88% 接地参考线、鼠标拖拽指示微动效、左右轮播翻页 |
| **右栏 5 色调色板** | `frontend/src/components/orbit/color-palette-bar.tsx` | 5 个 Hex 纯色块，支持悬停显示名称与一键复制颜色代码 |
| **右栏单品拆解卡片** | `frontend/src/components/orbit/garment-dock.tsx` | 透明底 PNG 缩略图、大写英文分类标题、面料描述、书签收藏按钮 `🔖` |
| **Canvas 2D 60fps 拖拽** | `frontend/src/components/orbit/sprite-sheet-scrubber.tsx` | 监听 Pointer/Touch 事件，映射 0~15 帧切片，显存常驻 ≤ 15MB |
| **端侧 2.5D 深度微动** | `frontend/src/components/orbit/parallax-canvas.tsx` | `onnxruntime-web` 动态 import，MiDaS 量化模型 WebGL 本地推理 |
| **多模态与外部适配器** | `backend/internal/adapter/orbitproviders/` | Gemini 2.0 Flash REST 调用，Fal.ai SAM2/BiRefNet 抠图，Fashn 换装 |
| **核心领域编排** | `backend/internal/application/orbit/` | 状态模型、领域异常、CIELAB K-Means 聚类、上下文并发控制 |
| **HTTP 契约与路由** | `backend/internal/adapter/httpapi/` | Huma DTO（`*_contract.go`）、路由（`*_routes.go`）、处理（`*_handlers.go`） |
| **GORM 领域持久化** | `backend/internal/adapter/postgres/orbit.go` | 自动化迁移、`orbit_looks` 记录持久化、租户级隐私隔离 |
