# 人物环绕与立体数字衣橱系统设计 (纯 API 与前后端契约架构)

## 1. 依据与核心设计决定

采用 [REQ-01](../requirement/01-人物环绕.md) revision 3、[RES-01](../research/01-人物环绕.md) revision 3。
本设计全面落实**“零自建算力、纯 API 组装、前后端全类型契约”**的工业级系统架构。

### 核心设计原则
1. **纯 API 编排，零 GPU 运维**：
   所有高阶视觉生成全部委托给成熟的托管 API（Gemini 2.0 Flash、Fal.ai / FASHN.ai、Fal.ai SV3D），后端不跑 Python 进程与显卡服务，服务器空闲成本为 0；
2. **前后端职责严格隔离与强类型契约**：
   - 后端 `/backend`（Go + Gin/Huma）作为唯一的**安全 AI 聚合网关与业务状态机**，自动生成 `/openapi.json`；
   - 前端通过 `@umijs/openapi` 自动生成全类型 Axios 客户端，保证 100% 编译期类型安全；
3. **分级体验与端侧零成本计算**：
   - 前端集成 `onnxruntime-web`，利用客户端 WebAssembly 本地推理 2.5D 深度视差，实现 300ms 内即时立体微动；
   - 前端采用 **Canvas 2D + 16 视角 WebP Sprite Sheet**，实现 60fps 稳定手势拖拽，常驻显存仅约 12MB。

## 3. 后端 `/backend` Huma 接口契约定义

后端暴露 3 个核心 API 操作，自动同步至 `/openapi.json`：

### 3.1 接口列表
1. **`POST /api/v1/orbit/analyze`（照片分析与单品解构）**
   - 接收全身照，并发请求 Gemini 2.0 Flash 提取季节温标风格，请求 Fal.ai 抠出外套/裤子/鞋单品；
   - 响应包含：`person_id`、`front_image_url`、`season_tags`、`temp_range`、`style_tags`、`extracted_garments`。
2. **`POST /api/v1/orbit/try-on`（原生姿态换装 - 快道）**
   - 接收 `person_id` 与 `target_garment_id`；
   - 调用 FASHN.ai / Fal.ai VTON，P95 ≤ 2.5s 输出新 Look 静态图（保持原有姿态面部）。
3. **`POST /api/v1/orbit/generate-360`（16 关键帧环绕 - 慢道）**
   - 接收 `look_id`；
   - 调用 Fal.ai SV3D 生成 16 个正交视角，拼接为单一 WebP Sprite Sheet，下发切片元数据。

### 3.2 核心数据结构 (DTO)
```typescript
// 单品 DTO
interface GarmentItemDTO {
  id: string;
  category: "outerwear" | "tops" | "bottoms" | "shoes" | "accessories";
  name: string;
  image_url: string;             // 干净白底图 URL
  is_occlusion_infilled: boolean;// 是否经过手臂遮挡补全

// 360° 雪碧图元数据

  url: string;                   // 4x4 WebP 大图 URL (~1.1MB)
  total_frames: 16;
  columns: 4;
  rows: 4;
  frame_width: 768;
  frame_height: 1024;
  anchor_frame_index: 0;         // 0° 绝对锚定原图
  is_loop_closed: true;
}
```

### 4.1 视觉标准与“高级感”落地
* **画布底色**：遵循 `DESIGN.md`，采用纯净无边框 `#fafafa`；
* **脚底接地基线（Foot Baseline）**：画布 Y 轴 88% 处设为接地参考基线，所有试穿与旋转图均对齐该基线，杜绝上下跳动；
* **柔和接触阴影（Contact Shadow）**：脚底附带椭圆羽化环境光遮蔽阴影（`rgba(0,0,0,0.12)`），避免人像浮空。

## 5. 容灾、超时与降级策略

1. **超时熔断**：任何外部 API（试穿或环绕）超过 25s 自动熔断，退回静态 2.5D 视差模式，前端提示“网络拥堵，已保留当前高清搭配”；
2. **本地模型兜底**：若客户端不支持 WebGPU/WASM，自动平滑退化为纯 2D 高保真图片展示，不阻断核心换装业务。
