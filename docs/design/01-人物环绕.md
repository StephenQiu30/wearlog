# 人物环绕与立体数字衣橱系统设计

## 1. 依据与设计决定

采用 [REQ-01](../requirement/01-人物环绕.md) revision 2、[RES-01](../research/01-人物环绕.md) revision 2。
本设计旨在以**最低算力开销、最短感知延迟、最高照片保真度**还原“Woo 立体数字衣橱”的端到端体验。

### 核心架构原则（避免过度设计）
1. **彻底摒弃三维网格建模**：不搞端上 3D Mesh、骨骼动画与物理布料解算；
2. **端侧播放彻底摒弃 MP4 Seek**：锁定采用 **WebP Sprite Sheet（雪碧图）+ Canvas 2D**，保证低端移动设备在 60fps 拖拽下绝对稳定、零抖动、零内存泄漏；
3. **动静解耦的两阶段流转**：
   - **快道（高频试穿）**：2D 换装（CatVTON，1.5s）+ 瞬时 2.5D 视差（Depth-Anything-V2，300ms），随心搭配不烧钱；
   - **慢道（按需环绕）**：用户满意确认后，才触发 16 正交关键帧扩散生成（Era3D/SV3D-Light），0° 强绑定原图保证完美闭环无缝。

## 3. 核心模块职责划分

| 逻辑模块 | 职责与技术选型 | 对应需求 |
| --- | --- | --- |
| **质检与档案管理** | 校验全身单人、头脚完整度、姿态有效性；提取用户人脸 Embedding 与体态掩码 | FR-01、NFR-05 |
| **2.5D 深度视差服务** | `Depth-Anything-V2-Small`，在 300ms 内输出灰度深度图；驱动端侧 WebGL 视差着色器 | FR-02、NFR-04 |
| **单品解构与清洗管线** | `Grounding DINO + SAM 2` 提取各品类 Mask；LaMa 补全手臂遮挡；`Gemini 2.0 Flash` 输出结构化打标 JSON | FR-03、FR-07 |
| **2D 极速换装引擎 (快道)** | `CatVTON / IDM-VTON`，基于用户姿态骨架进行单品服帖渲染，P95 ≤ 2.5s | FR-04、NFR-04 |
| **16 视角环绕生成器 (慢道)** | `Era3D / SV3D-Light` 定向相机扩散，输出 16 个方位图并拼装为单个 WebP Sprite Sheet | FR-05、NFR-01、NFR-02 |
| **Canvas 帧浏览器** | 监听 Touch 手势位移，计算当前朝向索引并重绘对应 Sprite 切片；支持反向、停帧与替代按钮 | FR-06、NFR-03 |
| **超时与容灾编排** | 设置 25s 熔断兜底；超时自动回退保留 2.5D 静态 Look，防止无限 Loading | NFR-04 |

## 5. 端侧交互与渲染实现设计

1. **Sprite Sheet 渲染算法**：
   - 设横向拖拽距离为 $\Delta x$，屏幕灵敏度系数为 $k$；
   - 当前视角帧索引：$Index = \left( \lfloor \frac{\Delta x}{k} \rfloor \pmod{16} + 16 \right) \pmod{16}$；
   - 根据 $Index$ 得到网格行号 $row = \lfloor Index / 4 \rfloor$，列号 $col = Index \pmod 4$；
   - 触发 `ctx.drawImage(sheetImage, col * w, row * h, w, h, 0, 0, canvasW, canvasH)`，无需任何 DOM 重排与多图网络请求。
2. **手势冲突隔离**：
   - 展台区域限制横向位移锁定为帧切换，超出 30° 倾角判定为页面纵向滚动，不发生手势抢占；
   - 底部保留快捷入口：“正向 (0°)”、“侧面 (90°)”、“背面 (180°)”按钮，支持无障碍/辅助访问。

## 6. 风险与容灾对策

| 潜在风险 | 消除措施 |
| --- | --- |
| 16 关键帧在 0° 视角接缝跳帧 | 将 0° 帧强制赋值为原图切片；多视角扩散算法使用原图作为正向先验条件 |
| 外部电商单品图光照差异大 | 在 VTO 预处理阶段进行直方图匹配与光照归一化 |
| 算力队列拥堵导致超时 | 超过 25 秒自动将状态设为 `failed_fallback`，弹窗提示并维持 2.5D 深度视差微动浏览 |
| 用户频繁切换 Look 产生并发任务 | 前端做防抖防重，服务端以 `LookVersionId` 进行幂等防重提交 |
