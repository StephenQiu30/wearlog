# 立体数字衣橱与穿搭需求规格 (Woo 1:1 复刻版)

## 1. 用户问题与核心目标

对标 **“Woo — Turn your outfits into a wardrobe”**（你的穿搭照片，不应该只停留在相册里），彻底解决时尚穿搭爱好者与普通用户“穿搭记录死在相册、实体衣橱杂乱翻找低效、购买新衣不知如何与旧衣搭配、传统试穿缺乏真实感与姿态保真”的四大核心痛点：

1. **唤醒相册穿搭**：将单张全身穿搭照片转化为**可 360° 拖拽交互的 3D 画报走秀台（Runway Stage）**；
2. **多维时尚解构**：深度解析穿搭的**季节适应性、温度区间、风格美学（如 Fairycore、Cleanfit）**，自动萃取 **5 色主色调色盘（Color Palette）**；
3. **高保真单品拆解**：精准分离并生成外套、上装、下装、鞋履、包袋、饰品等**发丝级透明底 PNG 抠图**，并配以专业时尚设计语言与面料描述；
4. **一键收藏数字衣橱（Digital Wardrobe）**：单品可一键书签（`🔖`）收纳进个人数字化衣橱，打破传统翻箱倒柜的低效管理；
5. **原生姿势自由换装（Virtual Mix & Match Try-On）**：支持从衣橱中任意点选单品，在**严格保持原有姿态、五官面容与身材比例**的前提下，将新衣物服帖换穿到照片人物上。

### 刚性技术与算力约束
- **零自建 GPU 算力**：团队不自行部署或维护任何显卡模型服务，全量功能通过**“成熟商用/Serverless API + 端侧轻量 WebAssembly”**实现；
- **前后端分工基线**：
  - 前端采用 **Vercel (Next.js) + shadcn/ui + Radix UI + Tailwind CSS v4 + ESLint + Prettier + Axios + `@umijs/openapi`**；
  - 后端采用 **`/backend` (Go + Gin/Huma + GORM + PostgreSQL + MinIO)**，负责与第三方 AI API 通信并输出 `/openapi.json`。

### 2.1 顶部导航栏 (Header)
- **品牌 Logo**：左侧 `WOO` 极简无衬线大写标题；
- **双模态切换胶囊 (Mode Switcher)**：居中 `[ RUNWAY | WARDROBE ]` 切换药丸，支持在“画报走秀”与“数字衣橱”之间无缝切换；
- **右侧功能区**：搜索图标（`🔍`）、上传/新建穿搭图标（`+`）、全局菜单（`☰`）。

### 2.2 左栏：穿搭时光轴与历史归档 (Look Archive Sidebar)
- **尺寸与折叠**：默认宽度 256px，支持通过顶部 `<<` 按钮向左平滑折叠；
- **历史穿搭卡片**：
  - 垂直长方形模特缩略图；
  - 季节与日期徽章（如 `☀️ SUMMER`、`JUL 18`）；
  - 风格化命名（如 `Pastel Blue Fairycore Cargo`、`Gothic Lolita Grunge...`）；
  - 选中激活态：左侧边缘高亮指示圆点 `●` 与微光边框；
- **底部筛选器**：支持按季节（春夏秋冬）、年份、风格过滤。

### 2.3 中栏：3D 画报主走秀台 (Runway Stage & Carousel)
- **主标题与归档信息**：如 `Pastel Blue Fairycore Cargo`，副标 `JUL 18, 2026 · PERSONAL ARCHIVE`，右上角时令徽章 `☀️ SUMMER`；
- **主舞台呈现**：
  - 固定 `aspect-[3/4]` 比例，低饱和莫兰迪色影棚背景；
  - 模特脚底严格对齐 88% 接地基线，带动态椭圆柔光软阴影；
  - **交互指引 (Interactive Affordance)**：展台中央浮现“鼠标横向拖拽”微动效图标，直观提示用户可旋转查看；
  - **画报轮播控制**：两侧悬浮左右翻页箭头（`<` `>`），右侧舞台边缘微露下一套 Look 的淡化边缘（Peek Card Effect），支持平滑翻页。

### 2.4 右栏：色彩提取与单品解构栏 (Color Palette & Items in this Look)
- **COLOR PALETTE（色彩提取）**：展示从搭配中自动萃取的 **5 色主色调色盘**，采用纯净圆角色块排列（如 `#FFFFFF`、`#F0F6F8`、`#A8C7F0`、`#CCD8E2`、`#F4EFE6`），支持悬停复制 Hex 代码；
- **ITEMS IN THIS LOOK（单品分解）**：
  - 单品品类全大写标题（如 `CROP CAMISOLE`、`CARGO JEANS`、`CHUNKY SNEAKERS`、`FAUX FUR HANDBAG`、`CHOKER AND NECKLACES`）；
  - 高精度透明底 PNG 抠图；
  - 专业设计语言与面料描述（如 *"White corset-style crop camisole with light blue lace trims, butterfly embellishments, and front ribbon tie-up."*）；
  - 单品主色标注（如 `#FFFFFF / #98C0F7`）；
  - **收藏书签按钮 (`🔖`)**：一键将单品收纳进个人“数字衣橱”，图标变为高亮实心，并弹出 Toast 提示；
- **底部快捷栏**：分享（Share）、海报导出（Download）、更多选项（...）。

## 3. 功能与非功能需求表

| 编号 | 需求名称 | 行为与实现机制 | 场景 / 异常处理 | 成功指标 / 验收方式 |
| :--- | :--- | :--- | :--- | :--- |
| **FR-01** | 全身照输入与基线定标 | 接收单张全身穿搭照，校验头脚完整度，统一脚底接地基线至 88% | 遮挡过重、半身照提示重新上传 | 正确识别单人全身，构图统一居中 3:4 比例 |
| **FR-02** | 端侧 2.5D 深度视差微动 | 前端利用 `onnxruntime-web` 本地推算深度图，驱动 WebGL 视差着色器 | 移动端陀螺仪或手指轻微晃动 | **0 算力成本，P95 ≤ 300ms**，首屏秒级立体反馈 |
| **FR-03** | 穿搭时令与风格语义解析 | 后端调用 Gemini 2.0 Flash 提取季节、温度区间、风格标签与画报大标题 | 风格小众或复杂混搭 | 准确识别品类与时令，生成专业时尚大标题，P95 ≤ 1.5s |
| **FR-04** | 5 色主色调色盘自动萃取 | 剔除背景与人体皮肤，通过 CIELAB K-Means 聚类提取 5 个最具代表性的 Hex 色值 | 纯单色或过于复杂的印花穿搭 | 提取符合时尚美学的 5 色色板，支持复制 Hex |
| **FR-05** | 单品发丝级解构与透明抠图 | 调用 Fal.ai BiRefNet/SAM 2 并发拆解外套、上装、下装、鞋履、包袋、配饰透明底 PNG | 复杂花纹背景、多件衣服重叠 | 准确识别品类，单品边缘平滑无白边，P95 ≤ 2.0s |
| **FR-06** | 单品设计与面料描述生成 | Gemini 结合局部区域生成包含版型、细节特征及面料材质的专业文字说明 | 复杂刺绣、抽绳、金属饰品 | 产出 20~40 词精炼时尚描述文本 |
| **FR-07** | 数字衣橱一键收纳 (Bookmark) | 右栏单品卡片点击 `🔖` 图标，将该单品持久化收纳进当前用户的数字化衣橱 | 重复点击或网络异常 | 实时入库，图标变为实心状态，支持去重与标签分类 |
| **FR-08** | 原生姿态 2D 试穿换装 (快道) | 选中衣橱单品后，后端调用 FASHN.ai / Fal.ai CatVTON API 执行换装 | 试穿失败或用户取消 | **P95 ≤ 2.5s**，严格保持原图五官、发型与站立姿势 |
| **FR-09** | 按需生成 16 关键帧 360° (慢道) | 用户满意当前 Look 点击“生成 360°”，后端调用 Fal.ai SV3D 生成 16 视角并拼装为 WebP Sprite Sheet | 生成超时或单次失败 | **0° 强绑定原图**，首尾接缝无感知跳动，超时熔断线 25s |
| **FR-10** | Canvas 2D 帧拖动浏览器 | 前端 Canvas 2D 监听 Touch/Mouse 水平滑动，动态映射 Sprite Sheet 切片 UV | 高频反向拖拽、松手停留 | **稳定 60fps 丝滑拖拽**，显存常驻 ≤ 15MB，无丢帧白屏 |
| **FR-11** | 时光轴轮播与海报导出 | 左栏列表点击与中栏 `<` `>` 翻页切换 Look；支持整套搭配图谱海报高清导出 | 切换不同穿搭 | 转场平滑无卡顿，一键导出 300DPI 个人时尚画报 |
| **NFR-01** | 视觉真实感与服帖度 | 正面换装及各角度过渡区域保持面料质感、光影衰减与真实褶皱 | 复杂图案印花 | 无明显塑料感、无融手穿模，视觉质量符合时尚影棚要求 |
| **NFR-02** | 闭环接缝无缝性 | 0° 视角与 360° 旋转交界处过渡完全平滑 | 在接缝处来回拖拽 | 0° 视角误差低于肉眼感知门槛，无闪烁跳帧 |
| **NFR-03** | 端侧性能与布局稳定性 | 固定 3:4 容器比例，采用 WebP Sprite Sheet (4×4 矩阵) | 连续切换多套搭配 | **CLS = 0**，显存占用 ≤ 15MB，离开页面纹理立即回收 |
| **NFR-04** | 成本控制与零自建 GPU | 核心算力完全依托成熟云端 API，单用户单次体验综合成本可控 | 算力空闲与洪峰 | 服务器空闲时 GPU 账单为 **0 元**，整套体验成本 ≤ 0.6 元 |
| **NFR-05** | 接口契约一致性 | 后端 Huma 自动生成 `/openapi.json`，前端通过 `npm run openapi` 自动同步 | 接口字段变更 | 前后端 TypeScript 类型 100% 编译期校验，无手工重复定义 |
| **NFR-06** | 隐私隔离与密钥安全 | 用户原图、人像档案与衣橱单品严格按账户物理隔离；API 密钥收拢于后端 | 会话过期、越权访问 | 私有 URL 需验签访问，日志与网络包严禁输出敏感 Key |
| **NFR-07** | 优雅降级与熔断机制 | 外部 360° 接口超时（>25s）时自动熔断并回退至 2.5D 深度视差微动 | 网络超时、第三方服务中断 | 界面不卡死，友好告知用户，试穿与单品拆解核心功能不受损 |
