# 需求

记录用户故事、目标、范围、功能需求 FR 与适用的非功能需求 NFR。明确已确认内容、假设和待决问题。

来源为用户诉求及 [research](../research/README.md) 的调研结论；交给 [design](../design/README.md) 形成方案。

## 主题

- [01 人物环绕](01-人物环绕.md)：照片质感与拖动效果优先，不以当前代码为依据。
- [02 立体数字衣橱与穿搭](02-立体数字衣橱与穿搭.md)：三栏画报走秀台、单品发丝级解构与面料描述、5 色调色盘萃取、数字衣橱收纳与试穿换装、多模态 AI 管道配置。
- [03 用户账户与认证](03-用户账户与认证.md)：邮箱密码极简认证、完全排除身材量度录入负担、个人公开名片 Handle、多租户资产物理隔离与 GDPR 彻底注销清扫。
- [04 预置虚拟模特与试穿人像](04-预置虚拟模特与试穿人像.md)：MVP 预置虚拟模特开箱即用（首发 4 款男女模特）、3D 走秀台模特切换器、本人全身照质检导入与试穿人像基准联动。
