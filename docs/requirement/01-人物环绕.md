# 人物环绕

## 1. 用户问题与已确认目标

2026-10-24，用户明确要求“接近 Woo 的照片质感与拖动效果”，并将其设为设计最重要的目标；同时要求当前代码不作为方案依据。参考 [Woo 演示](https://x.com/LerSentAI/status/2090783821452943404)，研究依据为 [RES-01](../research/01-人物环绕.md) revision 1。

首个增量服务于查看本人或授权人物穿搭效果的人：希望像浏览照片一样看清衣服，又能用手指连续查看侧面和背面。优先级是**照片质感与主体一致性 → 拖动连续性与可控性 → 生成成功率、等待和成本 → 功能数量**。质量、交互、成本均需分别达标，不能用功能多或“真正三维”抵扣视觉缺陷。

用户故事：作为穿搭查看者，我希望在一个稳定的人物画面中拖动查看不同方向，停在任意已支持方向检查细节；更换衣服后，先确认新穿搭图，再选择是否创建环绕。

价值：将单张穿搭照片扩展为可控的多方向搭配参考。是否减少实际试衣时间尚属假设，不宣称准确尺码、合身或消费决策效果。

## 2. 范围与非目标

本增量定义并验证：一张认可的完整 Look、连续环绕素材、水平拖动/停帧/反向浏览、已有 Look 切换、静态试穿与环绕分步、失败保留原内容。正式开发前先确认一套素材效果，再扩代表性衣物。

不纳入：任意俯仰相机、精确人体测量、尺码预测、实时布料、骨骼动作、三维单件网格换装、社区和商城。真实衣橱记录/实穿统计的完整系统不是本增量；若以后关联，生成和浏览不得自动计为实际穿着。

## 3. 功能与非功能需求

| 编号 | 行为或质量约束 | 场景 / 异常 | 成功条件 / 测量方式 |
| --- | --- | --- | --- |
| FR-01 | 使用有权使用的人物参考，保留原图与 Look 版本 | 原始输入与美化/生成结果不同 | 可区分来源；不能把美化比例当真实测量 |
| FR-02 | 静态穿搭结果被接受后，才按需创建环绕 | 不认可静态图、没有请求环绕 | 不创建环绕任务；不把静态图标为可旋转 |
| FR-03 | 支持水平拖动、反向拖动与松手停留 | 快速反向、缺失帧、首尾接缝 | 显示当前 Look 对应方向；无错帧或无法解释的跳转 |
| FR-04 | 切换已有 Look 时管理加载与缓存 | 新 Look 未就绪、旧解码晚返回 | 不串 Look；保留当前图或可解释加载状态 |
| FR-05 | 选新衣物生成新静态 Look，环绕单独创建 | 生成失败、用户切走、结果被拒绝 | 保留旧 Look 和输入；不承诺新组合瞬时全视角 |
| FR-06 | 区分排队、处理中、检查、可浏览与失败 | 服务完成但质量未通过 | 技术完成不等于视觉接受；可恢复并保留已接受静态图 |
| NFR-01 | 人物和服装达到可接受的照片质感与跨方向一致性 | 正面、两侧、背面、过渡、首尾 | 按 PRD 逐项人工评审；明显脸/体型/款式错误不能用平均分抵消 |
| NFR-02 | 连续一圈有真实方向覆盖 | 半圈折返、切镜头、独立图淡化 | 这些结果不通过完整环绕验收；推测背面如实说明 |
| NFR-03 | 拖动响应与切换可用 | 热缓存/冷加载/弱网分别测试 | 建议热缓存方向 P95 ≤100ms、Look 切换 P95 ≤200ms、交互目标 ≥30fps；为待确认实验阈值，不是已通过事实 |
| NFR-04 | 限制解码内存、及时停绘与回收 | 连续切换、进入后台、离开舞台 | 不全量解码所有 Look；按固定设备观测峰值与回收，具体上限在实验前确定 |
| NFR-05 | 输入、生成和缓存按用户与版本隔离 | 旧结果返回、任务超时、重复提交 | 不覆盖新版本、不显示他人内容、不盲目重复收费提交 |
| NFR-06 | 提供不依赖拖动的替代操作 | VoiceOver、键盘、Reduce Motion | 正侧背可操作；关闭非必要惯性与自动转动 |
| NFR-07 | 全部尝试成本与质量失败可追踪 | 拒绝结果、超时未知状态 | 记录投入/接受数、失败原因与分阶段等待，预算和重试上限先确定 |

## 4. 确认、假设与未决问题

已确认：照片质感与拖动效果为首要目标；本次整理到 docs；不参考现有实现。当前仅有文档整理授权，不能据此推导收费生成、采购、部署或代码开发。

建议：先验证“完整 Look → 环绕视频/帧 → 有限缓存浏览”，避免以三维建模为前提。目标使用者是本人/授权人物的穿搭查看者，不据此推断市场规模或多人产品范围。

实施前需要确定：首发平台与最低设备、认可的静态样本、生成供应商/数据条款、单套预算与尝试上限、背面参考要求、性能阈值与测试协议。未决项不阻止本文整理，但阻止对应生成、性能验收或接入任务就绪。
