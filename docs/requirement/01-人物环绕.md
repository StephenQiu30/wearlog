# 人物环绕与立体数字衣橱需求规格

## 1. 用户问题与核心目标

依据 2026-10-24 用户确认及 2026-10-29 深度求证，业务对标 **“Woo 360° 立体数字衣橱”**：
1. **唤醒相册穿搭**：将单张全身穿搭照片转化为**可拖拽查看的立体形象**，告别呆板平面照片；
2. **自动化单品归档**：智能识别整套搭配中的外套、上装、下装、鞋履与配饰，分析适合季节与风格，一键存入数字衣橱；
3. **保持姿态的随心换装**：挑选衣橱单品（或外部电商单品），在**严格保持原有姿势与体态**的前提下生成逼真试穿效果，摆脱反复翻找与穿脱衣服的繁琐。

设计首要优先级：**照片级质感与主体一致性 → 零等待感知（2.5D即时视差）→ 拖拽连贯性（360°无缝闭环）→ 低推理成本与稳定成功率**。拒绝过度追求笨重的三维网格建模与物理布料仿真，坚定采用“2D 深度视差 + 2D 高保真试穿 + 稀疏正交多视角关键帧（Sprite Sheet）”的务实工程路线。

## 2. 业务范围与边界

### 2.1 核心覆盖范围
1. **全身照输入与质检**：单张正向全身照，自动校验头脚完整度与人体姿态；
2. **分级立体呈现**：
   - **T+0.3s 感知视差**：单图深度计算，立即提供手指交互微立体倾斜反馈；
   - **T+N 按需 360° 环绕**：生成 12~16 个正交关键角度，打包为轻量 WebP 雪碧图，端侧实现无卡顿 360° 顺畅循环拖拽；
3. **穿搭解构与数字衣橱（Fashion Parsing & Wardrobe Ingestion）**：
   - 自动分割外套、上装、下装、鞋履、配饰，抠图生成白底单品图；
   - 对手臂/身体遮挡部位进行织物纹理补全（Inpainting）；
   - 输出结构化属性：适合季节（春/夏/秋/冬、具体温标区间）、风格与配色盘；
4. **保持姿势的虚拟换装（Pose-preserved Virtual Try-On）**：
   - 从衣橱中选择一件或多件衣服替换现有 Look；
   - 原生姿态、面部特征、未替换衣物及光影保持高度一致；
5. **外部单品扩展接入**：
   - 预留接收外部电商商品图（白底图/商品链接截图）作为换装源，充实数字衣橱。

### 2.2 非目标（排除过度设计）
- 不做任意空间自由俯仰的 3D 相机漫游（仅限水平轴环绕浏览）；
- 不做高精人体量体与三维尺码预测；
- 不做实时的 3D 骨骼蒙皮与实时布料解算；
- 不在手势高频交互中直接 Seek MP4 视频。

## 3. 功能与非功能需求

| 编号 | 需求名称 | 行为或约束 | 场景 / 异常处理 | 成功指标 / 验收方式 |
| --- | --- | --- | --- | --- |
| **FR-01** | 全身照输入与档案建立 | 接收全身穿搭照，建立用户数字体态档案（人脸特征、姿态骨架） | 遮挡过重、半身照、非单人照片拦截并引导重拍 | 正确识别单人全身，留白与基线自动归一化 |
| **FR-02** | 瞬时 2.5D 深度视差 | 上传后 300ms 内生成单图深度图，前端提供陀螺仪与轻微拖拽倾斜 | 全景 360° 尚未生成时 | 用户无枯燥等待感，感知延迟 P95 ≤ 300ms |
| **FR-03** | 单品自动解构与分析 | 像素级分割各单品，遮挡修补，生成白底图；多模态大模型输出季节与风格 | 内搭扎进裤子、手臂遮挡衣物 | 正确提取各品类单品，标明遮挡修补属性，季节与温标输出规范 JSON |
| **FR-04** | 原生姿态 2D 试穿 (快道) | 挑选单品触发 2D VTO，替换目标区域，严格保持原图姿势与人体轮廓 | 试穿失败或用户取消 | 2D 试穿推理时间 P95 ≤ 2.5s，保留原图与原 Look，不扣除环绕额度 |
| **FR-05** | 按需生成 16 关键帧 360° (慢道) | 用户确认满意 Look 后，生成 12~16 个正交视角，组装为 WebP Sprite Sheet | 视角模型生成畸变或超时 | 0° 视角以原图为绝对几何锚点，闭环无缝；超时 (25s) 降级保留 2.5D Look |
| **FR-06** | 交互式帧浏览器 | Canvas 监听手势位移映射雪碧图 UV 偏移，支持顺滑拖动、反向与停针 | 快速来回拖拽、网络弱网 | 稳定 60fps 交互，无白屏、无掉帧，停止即停帧 |
| **FR-07** | 外部单品引入 | 支持上传外部商品图或解析电商主图作为单品入库试穿 | 外部图片背景复杂 | 自动扣除杂乱背景，转为标准试穿源 |
| **NFR-01** | 视觉真实感与一致性 | 正面、侧面、背面及过渡区域保持人物五官、体型、衣服细节一致 | 背面推测标记 | 避免人脸崩塌或衣物款式突变，明显缺陷即判定不合格 |
| **NFR-02** | 闭环接缝平滑度 | 0° 与 360° 旋转交界处过渡自然 | 手势在接缝处来回拖动 | 0° 视角误差低于像素抖动感知门槛，无闪烁跳帧 |
| **NFR-03** | 端侧性能与内存预算 | 采用 WebP Sprite Sheet，禁止解码内存无界扩张 | 连续切换 10 套 Look | 显存常驻 ≤ 30MB，离开舞台立即释放纹理 |
| **NFR-04** | 服务端 SLA 与超时熔断 | 2D 试穿 P95 ≤ 3s，360° 关键帧生成 P95 ≤ 8s，全链路超时熔断设为 25s | 高峰期队列阻塞 | 超时自动退回并提示“网络繁忙，已保留高清静态立体图” |
| **NFR-05** | 隐私与数据隔离 | 用户原图、体型档案与衣橱单品严格按账户物理隔离 | 会话切换、未授权访问 | 私有 URL 需验签访问，日志中不打印媒体密钥 |
