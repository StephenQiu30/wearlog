# 预置虚拟模特与试穿人像需求规格 (Woo 1:1 复刻版)

## 1. 用户问题与核心目标

在 Woo 立体数字衣橱的核心玩法中，用户需要一位“模特”作为试穿与 360° 走秀的视觉载体。但真实场景中存在显著的用户冷启动痛点：

1. **新用户冷启动壁垒（相册无现成合规照片）**：
   - 用户首次打开应用，相册里往往没有满足“单人、全身、头脚完整、浅色背景、正向站立”质检标准的真实穿搭照；
   - 强行要求用户必须先上传全身照会导致大量新用户直接流失；
2. **拒绝繁琐的身材测量与录入**：
   - 用户使用数字衣橱的目的是轻松看搭配、玩转 3D 走秀，不希望像做体检一样繁重地去量身高、体重、三围；
3. **系统预置虚拟模特（开箱即用 0 秒体验）**：
   - 系统在 MVP 阶段预先生成并内置 **4~6 套标准高品质虚拟模特形象**（男女兼备、多元穿搭风格、标准模特身材比例）；
   - 每一款预设模特出厂即自带发丝级透明底抠图与 16 帧 360° WebP Sprite Sheet；
   - 用户进入 3D 走秀台，无需上传照片即可直接拖拽模特旋转，并在数字衣橱挑衣服一键试穿；
4. **本人真实人像的随心导入与双模切换**：
   - 当用户准备好本人的真实全身照时，可随时导入；
   - 走秀台提供简洁的模特切换器（Mannequin Selector），用户可在“预设模特”与“本人照片”之间自由无缝切换。

### 明确排除的非目标 (Explicit Non-Goals)
- ❌ **不做任何身材身体数据表单录入**（零门槛上手）；
- ❌ **不与用户账户认证混杂**（纯粹作为穿搭与走秀的视觉载体）。

### 2.1 走秀台模特切换器 (Model Selector)
- **位置**：位于中栏 3D 画报走秀台上方；
- **组件结构**：水平轻量胶囊单选组（Segmented Pill / Toggle Group）；
  - `[ ● Maya (女模-法式) ]`
  - `[ Leo (男模-日系街头) ]`
  - `[ Chloe (女模-甜酷) ]`
  - `[ Ethan (男模-极简工装) ]`
  - `[ + 上传本人照片 ]`
- **交互行为**：
  - 用户点击不同模特胶囊，展台人像产生平滑 Cross-Fade 渐变切换，无需整页重载；
  - 切换模特后，展台的 360° 拖拽精灵图、脚底阴影和默认试穿基准即刻同步更新。

### 2.2 本人人像导入与自适应质检弹窗
- 点击 `[ + 上传本人照片 ]`，唤起全身照上传抽屉；
- **智能质检反馈**：
  - 头顶是否完整保留（保留 5% 顶部留白）；
  - 双脚是否踩实（下边缘自动居中吸附至 88% 接地参考线）；
  - 自动提示背景杂乱度；
- 导入成功后，该人像自动成为模特切换器中的一项，并可作为默认基准保存。

## 3. 功能与非功能需求表

| 编号 | 类别 | 需求名称与行为定义 | 异常与边界 | 成功指标 / 验收方式 |
| :--- | :--- | :--- | :--- | :--- |
| **MOD-FR-01** | 预置资产 | **MVP 预置虚拟模特开箱即用**<br>内置 4~6 款标准男女时尚模特，包含立绘、透明抠图与 16 帧精灵图 | 网络弱网加载中显示骨架屏 | 新用户注册后 0 秒即刻体验 3D 走秀台左右拖拽与试穿 |
| **MOD-FR-02** | 模特切换 | **走秀台多模特无缝切换**<br>展台上方提供模特胶囊选择器，点击在多款预设模特之间平滑切换 | 切换中保持当前选中的单品不变 | 切换动画流畅（过渡 ≤ 200ms），展台 360° 精灵图与试穿立绘实时同步 |
| **MOD-FR-03** | 试穿联动 | **选衣即刻基于当前模特试穿**<br>在数字衣橱点选任意上装/下装，以当前展台模特为底板调用 2D 换装快道 | 换装失败回退至原模特立绘 | **P95 ≤ 2.5s** 出图，严格保持所选模特的五官、发型与站立姿势 |
| **MOD-FR-04** | 本人导入 | **本人全身穿搭照导入与质检**<br>点击 `+ 上传本人照片`，自动进行头脚完整性校验与 88% 居中基线标定 | 半身照或遮挡过重给出明确重拍引导 | 质检通过后作为“自定义模特”加入切换器，支持随时切回预置模特 |
| **MOD-FR-05** | 基准固定 | **一键绑定为默认试穿人像**<br>用户可将某位预设模特或本人照片一键设为“默认试穿基准” | 默认模特被删除时自动回退至预设 A | 下次打开应用自动恢复该模特视图，免去重复选择与上传 |
| **MOD-NFR-01**| 性能 | **预制 Sprite Sheet 秒级加载**<br>预置模特精灵图采用 CDN 边缘缓存与 WebP 强压缩 | 弱网环境下分块流式加载 | 首屏预置模特精灵图下载与解码加载耗时 **≤ 800ms** |
| **MOD-NFR-02**| 交互 | **Canvas 2D 拖拽帧率稳定性**<br>任何预置模特在水平拖拽旋转时保持帧率稳定 | 快速反向频繁拖拽 | **稳定 60fps**，无丢帧、无闪烁，常驻显存 ≤ 15MB |
| **MOD-NFR-03**| 质量 | **模特自然质感与姿态保真**<br>预置模特五官自然，肤色与面料质感真实，无 AI 假人感 | 避免恐怖谷效应与假面感 | 视觉质感达到时尚画报出版物级别 |
